## 安全性修正と小型テスト

- `low_rank.py` の `MyConv1D` は `u` を小さい乱数、`v` をゼロで初期化します。開始時の追加重みはゼロのまま、低ランク行列を学習できます。
- ベース重み・バイアスだけを凍結し、入力への勾配を維持します。元の層と同じdtype/deviceでアダプターを作成し、指定したrankを使用します（省略時8）。
- CPU用PyTorchとpytestを用意し、リポジトリ直下で `python -m pytest -q` を実行してください。テストは外部モデルやデータを取得しません。
- 確認済み：初期出力の一致、3回の更新で低ランク積が変化、ベース重みの不変、入力勾配、非contiguous入力、dtype/rank。
- 既存のゼロ固定されたアダプターは、この変更だけで復活しません。再初期化・再学習してください。学習済みアダプターを読み込む際に自動で乱数再初期化はしません。
- モジュール分離により全モデルpickleのクラス参照先が変わる可能性があります。旧pickleの自動読み込みは実装していません。構造を明示して `state_dict` を使用してください。rankを指定した旧実行でも実際は8固定だったため、古いstate_dictの形状に合わせてrank=8を明示する必要があります。
- 元の大規模学習スクリプトは旧Transformers APIなどにも依存します。今回、その外部モデル/GPU学習/保存済みモデルの復元までは検証していません。
